        <li><b>Centralized Ingress/Egress Inspection:</b> Implemented Azure Firewall / NVA with User Defined Routes (UDR) for strict perimeter egress filtering.</li>
        <li><b>Hybrid Connectivity:</b> ExpressRoute & Site-to-Site VPN gateways connecting on-prem datacenters with non-overlapping IPAM / CIDR allocations.</li>
        <li><b>Private Link Ecosystem:</b> Secured database and PaaS access using Private Endpoints and centralized Private DNS Zones.</li>
      </ul>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h4>🚀 3. 100+ Enterprise App Migration & Modernization</h4>

        <li><b>Checklist Governance:</b> Rigorous pre-migration readiness, during-cutover coordination, post-migration health checks, and hypercare support.</li>
        <li><b>High Availability (BCDR):</b> Multi-region deployment, VMSS auto-scaling, LRS/ZRS/GRS replication, meeting strict RTO & RPO recovery targets.</li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h4>🛡️ 4. DevSecOps & Terraform Automation</h4>

        <li><b>Branch Governance:</b> Trunk-based branching strategy, mandatory PR code owners, protected main branch, and zero-touch rollback templates.</li>
      </ul>
    </td>
  </tr>
